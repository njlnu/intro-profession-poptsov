На занятии я создал репозиторий на GitHub и сделал в ноутбуке поиск фильмов через OMDb API. Создать репозиторий и ветки оказалось проще всего. С настройкой ноутбука я возился дольше, особенно с командами для создания .venv и установки библиотек. Теперь понятно, что .venv нужна, чтобы у каждого проекта были свои библиотеки.

С ветками я запутался, когда скачал ноутбук из main, где ключ ещё вводился вручную. В main у меня лежит основная версия, а в env-feature я попробовал читать ключ из .env. Этот файл хранится локально, потому что в открытом репозитории ключ сможет увидеть любой. На GitHub я в итоге нашёл нужную версию по списку веток над файлами. Если делать коммит сразу после законченной правки, её потом легче найти в истории.

В работе с API мне понравилось, что из ответа в формате JSON можно взять только нужные поля, например название фильма, год и рейтинг. На ревью Giga Code заметил, что запрос отправлялся по HTTP, и предложил перейти на HTTPS, чтобы защитить ключ при передаче. Если бы я делал эту работу заново, то сразу записал бы команды для настройки окружения в том порядке, в котором они нужны.
