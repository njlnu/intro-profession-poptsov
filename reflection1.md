На занятии я разобрался, как отправить запрос к OMDb API из Python и получить данные о фильме. На GitHub у меня лучше всего получилось создать репозиторий и ветки. Дольше всего я возился с настройкой ноутбука, особенно с командами для создания виртуального окружения и установки библиотек. Теперь мне понятно, что в .venv у проекта есть отдельное окружение Python со своими версиями библиотек.

С ветками я тоже запутался и сначала скачал ноутбук из main, где ключ ещё вводился вручную. В main у меня лежит рабочая версия, а в отдельной ветке env-feature я мог проверить вариант с чтением ключа из файла. Ключ хранится в локальном .env, потому что прямо в коде его увидел бы любой, кто откроет публичный репозиторий. Коммит сохраняет изменения в истории проекта, и если делать его сразу после законченной правки, потом проще понять, что поменялось. В браузерной среде результат появлялся прямо под ячейкой, поэтому я мог сразу посмотреть, какие данные выводит мой код.

OMDb возвращает данные в формате JSON, и я разбирал этот ответ, чтобы вывести нужные поля, например название, год и рейтинг фильма. На ревью GigaCode заметил в коде запрос по HTTP и предложил перейти на HTTPS, чтобы ключ передавался по зашифрованному соединению. В следующий раз я бы сразу записал команды настройки окружения в том порядке, в котором их нужно запускать.
